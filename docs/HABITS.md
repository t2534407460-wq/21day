# 通用习惯模块（0.9.0）

状态：已修改待测试。保留作息首页与底部「习惯」，首页提供紧凑打卡抽屉入口，打开后左右切卡，可选择习惯并按区间、次数、每日确认与手填分区，按钮长按约650毫秒执行一次。短按、滑走取消、长时间按住不连记。系统关闭动画时停用抽卡过渡与烟雾。

## 使用

1. 「习惯 → 添加习惯」，选择阅读、运动、戒烟或自定义。设置名称、开始日期、目标、每周执行日期与一个提醒时间。每轮21个自然日，可同时管理多个计划，休息日不要求打卡。
2. 阅读、运动使用时段计时：长按开始、长按结束，保存每段起止时间，累计每日分钟，余秒保留并继续累计。跨午夜归开始日期；退出、重开仍可结束计时，不需要常驻服务。戒烟可选断崖式每日长按确认零支，或每日控量（默认上限10支），每次长按增加一支并显示短暂烟雾。允许超限如实记录。自定义可选时段或次数、至少或上限目标；旧手填习惯保留。
3. 长按累加到当天记录；也可填写实际总量和备注。手填保存替换总量，不再次累加；修改计时总量会清除该日时段明细，只改备注则保留。日历支持补记已到的执行日、确认撤销；未来和休息日禁止打卡。普通打卡不产生起床验证或睡前完成状态。
4. 详情查看21天日历、每周达标次数、已记录次数与记录日均。数量图柱/点代表实际值，短线代表当天目标，缺失留空。达标按该日规则判断；缺失不记零、不算已完成，今日未记不计入“过去未记录”。
5. 调整名称立即显示；目标、星期和提醒从次日或尚未开始的起始日生效，过去与今天保持原安排。单位、计量方向和开始日期在本轮固定，避免混合单位统计。重复调整同一生效日替换待生效安排。
6. 运行中的计时须先结束或确认取消，才能归档。归档停止提醒并保留记录，归档日后的日期不计入计划日。归档记录只读，仍可点日历查看。结束/归档后“开始新一轮”复制设置，创建独立的新ID，原轮次保留。

## 提醒和数据

- `HabitReminders` 独立使用 AlarmManager 和“习惯打卡提醒”通知渠道，不响起床铃、不锁屏。每个未记录计划日最多一次；消息打开习惯模块。提醒不写打卡。
- 已有精确闹钟权限时按用户时间调度；未授权时使用非精确提醒并提示可能延迟。通知关闭时显示开启入口。系统强行停止、关机和省电限制可能影响执行。依据：[Android 闹钟文档](https://developer.android.com/develop/background-work/services/alarms)、[通知权限](https://developer.android.com/develop/ui/compose/notifications/notification-permission)。
- 沿用 RescheduleReceiver 的重启、时间/时区变更、升级与权限授权重排链。上一份待分发提醒同一天仍有效时保留；不跨日追发过时提醒。
- `rhythm` preferences 的 `habits` 保存计划、规则历史和记录；规则按生效日有序，记录按ID＋日期唯一。`habit_reminded` 和 `habit_alarm_at` 保存本机提醒状态，不进入备份。
- JSON schema=2备份含习惯和打卡，无作息计划可导出恢复。旧schema=1只替换作息部分，保留本机习惯；新版恢复替换习惯。完整校验后统一提交，失败不覆盖。最多200轮/4200条记录，沿用2MB导入上限；不含密钥、验证点和聊天。
- 趋势与规则提示在本机计算。按用户新要求，开启自动复盘并配置Key后，后台向DeepSeek提交周期内的名称、目标、日期、实际数值，生成独立周报与21天报告，不发送备注、验证点或聊天。详见 CLOUD_COACH.md。聊天与补记的数据范围保持。

## 保留

作息首页、21天一晚接次晨、睡前问询、到点未打卡锁屏（0.9.0按新要求替代一小时宽限）、全部验证后自动记醒后、应用限制、扫码/NFC、正式应急退出、历史聊天与密钥、版本升级校验均保持。

21天是尝试和复盘周期，不保证届时养成。戒烟模板用于自我记录；没有自动识别、戒断治疗或医学建议。通用习惯不额外锁机。


## 新存储与兼容

- Habit 新增 input、smoking；旧阅读/运动且单位为分钟的计划使用计时，原支数戒烟使用计次（不改历史目标），其他旧类型保留。现有计划本轮不能静默切换计量方式，换类型可新建一轮。
- HabitEntry 新增 sessions（每段开始/结束毫秒）及 remainderSeconds；手填旧总量保留，后续计时在此基础累计。
- habit_timers 在本机保存各习惯运行中的开始时刻与开始日期，重开恢复；计时不进入JSON备份，schema2恢复取消运行中计时，已结束时段随打卡备份。schema1恢复保留习惯及计时。
- 定时提醒仍是固定时间；新建戒烟默认取当前作息的下次睡前提醒时间，可调整，之后不自动跟随睡眠计划变化。

## 设计核对

沿用 Paper #F7F5EF、Sage #E7ECDF、Ink #283B32、Moss #536547、24dp卡片圆角与平面圆形按钮。今日抽屉使用较小的平面卡片与左右切换，桌面用可上下滑动的叠卡；不加入高光、3D球体或新组件库。Design Read：面向日常自我记录的移动端增量改版，保留安静的纸白浅绿，加入有目的的触感动作；DESIGN_VARIANCE 4、MOTION_INTENSITY 5、VISUAL_DENSITY 4。基于现有Compose/Material3，网页专属CSS、SEO、安装框架要求不适用，未更改全局明暗主题。

交互参考官方 [Habitify Timer](https://habitify.me/onboarding-instruction/use-timer) 的时段记录思路和 [Streaks](https://streaksapp.com/) 的按任务打卡；未复制其界面或素材。烟雾由Compose Canvas绘制，仅在吸烟记录后短暂淡出。


## 桌面卡组

每个小组件可以独立选择已有习惯；移出卡组不删除计划和记录，不取消提醒。计时与计数分区延用习惯定义，不在卡组中更改计量类型。桌面长按交给系统移动/编辑，点开卡片在抽屉里持续长按约650毫秒打卡。配置和卡组选择只保存在本机，备份内容范围不变。详见 [WIDGETS.md](WIDGETS.md)。


## 动作画面（0.10.1）

用户于2026-10-04追加要求去掉0.10.0的人物，只显示主体：控量吸烟为香烟点燃、烟头和上升烟线，运动为哑铃起伏，阅读为书页翻动，自定义为笔记本与书写的笔。断崖式确认零支仍使用未点燃/划除画面。按住时预备、成功后短暂反馈；正在计时的阅读/运动/工作有循环动作。遵循系统动画开关，切后台停绘，任何动画帧都不会写记录。

`Habit.visual` 保存模板画面，重命名、新一轮、导出恢复仍保持；旧数据缺字段按原模板名/吸烟标识兼容，旧自定义已改名的模板来源无法推断，不批量猜测。未改变input、smoking、日总量/时段、备份schema或650ms长按规则。
