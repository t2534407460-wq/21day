## 2. 本项目负责的后端与数据

拟新增 `https://zhuisu.leadjet.com.cn/21day-api/v1/`，独立ASP.NET Core服务、`day21_db` 与 `day21_app` 数据库角色、独立附件和密钥命名空间。首批代码已放本地 `backend/`；原私有版本库规划已由2026-10-05用户明确提交源码要求替代，本项目后端源码纳入现有21day仓库，私有共享依赖包和部署凭据不入库。账号由独立 `/identity/v1/` 提供稳定user_id，本项目只接受audience/scopes符合21day的访问令牌。

21day是作息、习惯、日总量、计次、计时、规则历史、手机设置/外观、聊天和复盘的权威来源。Open Island只保存可重建的展示副本，写操作必须到本项目接口。Open Island原生待办只在独立关联区域展示，不自动转换为习惯；sMES文档通过授权引用使用，不复制为本项目可改的原文。

数据键为来源项目＋实体类型＋实体ID；同名习惯不能合并。日记录唯一键为用户＋轮次ID＋业务日期，规则包含生效日期和revision，验证结果保存其实际来源。

## 3. 邮箱账号与全量迁移

Android使用邮箱与密码登录；注册/密码重置验证6位邮箱验证码；新密码至少9个字符，含字母、数字、标点/符号，空白不算符号。身份服务生成稳定user_id，Keystore保护设备会话并保留数据集归属。公共邮箱只作发件地址，不共用用户密码。实际发信仍需受限SMTP凭据和真实验证。原微信方案已由2026-10-05用户要求替代，详细历史保留。

首次登录先预检并确认归属账号，云端非空时逐项合并；退出/换号隔离本地库、未发队列和附件。稳定source_store_id与迁移批次保证重试不重复导入。

| 数据来源 | 迁移内容 | 关键处理 |
| --- | --- | --- |
| `rhythm` / Store | 作息计划、现行及待生效规则、日记录、事件、验证点与偏好 | 规则和验证结果不因恢复重新执行；权限需求重新确认 |
| `rhythm` / HabitStore | 习惯、历史规则、日总量、时段、余秒、运行计时 | 原子迁移，不能把运行计时清零；归属业务日与原值一致 |
| `coach_chat` 与AI设置 | 聊天、提供商配置、输入法偏好、模型Key | 聊天独立项目恢复；Key走加密保险库，不进普通JSON |
| `habit_reviews` 及复盘设置 | 报告状态、事实快照、AI文字、周/周期设置 | 旧报告保留，恢复不重复请求AI；原星期日至星期六周口径保留 |
| 小部件与界面存储 | 选择列表、卡组/小卡类型、视觉参数、动效、用户素材 | Widget ID按本机重建；系统宿主尺寸/权限不能照搬 |

实施前枚举全部实际偏好文件与key，以上是已发现来源，不是未经检查的完整性承诺。现有schema2导出不包含聊天、报告、Key和运行计时；新账户迁移独立版本化，原schema1/2导入边界不变。密钥与系统授权不能通过复制Keystore文件恢复。

首批6类偏好已使用SQLiteOpenHelper/WAL及ProjectPreferences保持旧SharedPreferences接口，数据/迁移标志/待发队列同事务并保留原XML；这是本地事务基础，尚无网络上传/拉取。后续仍需完整领域实体与同步适配，旧偏好备份、校验和迁移完成标志齐全后再切换对应来源。现有代码所有写入口必须统一进入事务层，包括小部件进程、计时、聊天补记和后台复盘，不能只改主界面。

## 4. 手机到灵动岛的完整闭环

1. 手机创建习惯，本地保存并入Outbox；21day后端校验后存权威数据与跨项目事件。
2. Open Island接收事件，显示21day来源卡、当日目标和状态。移出卡片只是桌面偏好，不影响本项目计划。
3. 桌面计次、计时、总量更正或归档直接调用本项目业务命令，保留输入方式、日期、规则与revision校验。
4. 手机拉取21day增量刷新页面/小部件；报表按同一事实重算。同步过去记录不得重新响旧闹钟。
5. 21day“关联事项”反向引用桌面待办，完成/延期调用Open Island；不把它计入习惯达标率。

计次每次操作有幂等ID；总量更正用revision替换；计时会话有ID与负责设备。两个离线设备同期开计时不能直接相加冒充准确时长，保留冲突并提示处理。无网络仍能在本机记录，待发状态明确；Android后台受省电限制，不承诺离线/关机实时同步。

正式起床闹钟由手机执行。普通习惯默认保留手机提醒，桌面先展示事项；可选择两端提醒，但完全离线下无法保证只响一次。休息日自然醒和工作日验证路径不由云端缓存强行覆盖。

## 5. 报表与知识接入

手机继续提供原生周报、21天趋势与事实快照；Open Island汇总时带来源/周期/规则版本/单位与源水位。已记录0与未记录分开，分母剔除未来日和非执行日；次数、分钟、支等单位不混加。补记生成新报告修订，不抹去旧AI建议。

知识入口仅供有授权用户检索sMES指定版本、阅读来源、收藏批注、把文档关联到某轮学习习惯。普通已验证邮箱账号不自动获取MES权限；个人聊天/打卡不会批量发布成知识文档，App不持有知识发布密钥。查询先按权限缩小范围再排序，来源/图片/文件鉴权一致。
