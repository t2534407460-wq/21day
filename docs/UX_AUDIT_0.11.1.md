# 0.11.1 页面与操作审查

日期：2026-10-05（Asia/Shanghai）。状态：**已修改待测试**，用户实机尚未验收。

## 本轮目标

统一账号与限制页的视觉和操作；按用户追加要求检查所有主要页面入口、返回、空状态、操作反馈与取消行为。保留原生 Material 3、纸白/浅绿/深绿主题及现有底部五个入口。

## 规则与验证边界

- 临时次数是本机运行状态，和原临时放行一样不云同步、不进入JSON备份；账户切换/重新打开页面不恢复次数。
- 跨午夜的5分钟授权正常到期，新自然日额度恢复3次；同一授权期间重复点击不计次也不延长。
- 旧版当日已用的一次从旧到期时间与旧时长推导，计入新额度；旧强制解除标记不再绕过限制，旧历史事件保留。
- 旧备份/同步的passMinutes与passWait字段保留可读，运行时固定5分钟且无等待，设置页不再提供调整入口。
- 起床正式应急等待60秒+长按5秒、休息日自然醒、规则延后生效、白名单、长按650毫秒、计时/计数与历史目标均保留。
- 各自动化用例与失败复测的最终结果记录于本轮Debug；本表列审查覆盖，不等同每种手机、输入法、权限组合都已验收。
- 小米15/澎湃OS3、真实邮箱验证码、实体扫码/NFC、真实AI/跨设备服务器操作仍需用户验证。没有发送真实验证码或使用真实API密钥完成测试。
