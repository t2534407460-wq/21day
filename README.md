## 开始使用

1. 从 [GitHub Release](https://github.com/t2534407460-wq/21day/releases/tag/v0.12.1) 下载并安装 `21day-0.12.1-debug.apk`，可覆盖现有版本并保留记录。也可从「设置 → 数据与更新 → 检查更新」检查已发布版本。可先创建作息计划，也可直接进入「习惯」创建阅读、运动、戒烟或自定义计划。
2. 在「设置」开启通知、精确闹钟、锁屏闹钟、睡前到点锁屏（系统设备管理）、无障碍应用拦截权限。必要时在小米系统中允许自启动和后台运行。
3. 选择受限应用和额外放行应用。电话、系统闹钟、桌面、系统设置、权限管理等必要功能不拦截。
4. 保存起床二维码，打印并放到洗漱区；或者绑定固定放置的 NFC 标签。标签绑定只读取标识，不写入卡片。
5. 先运行「试一次应用拦截」和「试一次起床验证」。试用起床流程不计入正式日常记录。
6. 在正式依赖叫醒前，完成 [小米 15 人工测试清单](docs/TESTING.md)。
7. 每晚打开「开始睡前打卡」，用圆球或点选回答困意、心情和影响原因；每步保存草稿，最后点「完成睡前打卡」。可选记录小行动、上床时间和备注。到计划睡前时间仍未完成时，授权后执行一次系统锁屏；已完成则取消，解锁后可补打卡。
8. 「设置 → 权限与后台 → 隐藏最近任务卡片」默认开启，从任务列表隐藏廿一，桌面图标仍能打开。需要上锁时先关闭隐藏，上锁后再开启；小米是否保留锁定需实机核对。隐藏不代表保活，仍需自启动和电池无限制。
9. 正式闹钟正常结束需扫码 / NFC。应急退出须在窗口内等待 60 秒后连续长按 5 秒；松手或移出按钮重置长按，窗口关闭或切到后台重新等待，退出记为未验证。试用闹钟可直接结束。
10. 「设置 → AI 助手」填写自己的 DeepSeek API Key，再从「记录助手」聊天，无需下载模型。可连续聊天、语音转文字后发送，也可快捷生成今日/近7天总结与建议，或切换“补记”；按 API 账户计费。补记显示日期及原值/新值，确认后才保存。不再读取或发送 Health Connect 数据。

## 明确的边界

- 超时锁屏需系统设备管理和精确闹钟权限，每晚一次；不设置或更改密码，未设密码时只熄屏。锁屏后可能要求密码解锁，不防止用户自行解锁或撤销授权。强行停止、关机、省电限制可能延迟或阻止调度。
- 午夜后至计划起床前的打卡归前一晚；进入下一晚时不追补更早夜晚的锁屏。旧行动状态不等于新睡前打卡，助手自述时间不等于验证。

- 21 天是启动周期，不保证在指定天数形成习惯。
- 关闭通知不取消拦截规则；但撤销无障碍权限、强行停止、卸载、关机等能影响执行，普通个人应用不能阻止这些系统操作。
- 闹钟「安静验证」不等于已经起床；只有正确的二维码 / NFC 才推进验证。完成验证也不保证之后不会再睡。
- 无回应只记录为未确认；不因手机静止、手表没戴或数据缺失而判断仍在睡觉。
- 不接入小米运动健康或其他手表数据。扫码/NFC 完成状态只表示验证动作完成。
- Redmi Watch 6 的独立应用、实时步数 / 心率流、手机与手表第三方闹钟同步未实现。手机叫醒独立运行。
- 通用习惯使用长按计时、计次、每日确认及手填校正；不读取步数、不自动检测吸烟或运动，也不触发作息锁屏。作息聊天仍处理作息数据，自动复盘按习惯分别提交周期统计。
- 恢复备份会替换计划和日常记录；权限、验证点、本机事件记录不从文件覆盖。主动夜间限制或起床验证期间拒绝恢复。
- 应用没有自建账号、广告或数据分析 SDK。联网用于GitHub静默/手动更新检查、主动聊天及已开启的DeepSeek自动复盘。聊天发送近7天作息统计及最近最多12条聊天消息（总正文约2万字符上限）；总结发送所选日期统计；补记发送本次原话和已解析日期。手机语音服务可能联网，廿一不保存录音、不自动发送识别结果。聊天仅本机保留最近60条，不进入作息备份。不读取或发送手表睡眠数据，保留旧版本已保存的总结文本。API Key 在手机输入，以 Android Keystore AES-GCM 加密保存在 noBackupFilesDir；不进入备份、总结或日志。无需本地模型；普通记录、闹钟和统计无需联网。
- 模型可能误解日期或字段。不能自动判定实际睡眠、不能代替医疗判断，也不会自动调整计划、限制或闹钟。聊天中的今日/7天总结各保留最近一次；自动复盘按习惯和周期分别保留在看板。总结和 API Key 不包含在 JSON 备份中，已确认的补记仍作为 DayLog 正常导出。
- 聊天中停止请求、离开页面或切后台会断开本机接收；自动复盘则由后台任务执行，但不能撤回已发送的数据，服务端可能已处理并计费。密钥保存不代表联网验证通过，失效、余额不足、限流等会在实际请求时提示。
- 后台上锁、自启动及省电策略由手机系统管理；隐藏卡片、上锁和收起页面均不保证进程始终存活。

## 构建

JDK 17、Android SDK Platform 36、Gradle Wrapper 8.13。最低 Android 9 / API 28，targetSdk 35。无需安装全局 Gradle。

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

通过 `ANDROID_HOME` 指向 SDK，或在不入库的 `local.properties` 中填写本机路径。APK 输出在 `app/build/outputs/apk/debug/app-debug.apk`。

`backend/` 为本项目的 .NET 10 服务源码。它依赖私有共享包 `ProjectInterop.Sync` 0.1.4；依赖包不入库，需从授权的共享协议项目获取后放入 `backend/packages/`，再执行 `dotnet restore backend/Day21.Server.csproj`。后端连接配置、身份服务和加密密钥需在部署环境单独配置，不随源码分发。
